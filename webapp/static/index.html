Order matters

Softmax sees 4 unrelated boxes

Calling a rotten fruit unripe costs exactly as much as calling it ripe. The loss has no idea the grades sit on a line.

Ordinal regression asks 3 yes/no questions

0123
grade > 0 ?0111
grade > 1 ?0011
grade > 2 ?0001

Grade = number of “yes” answers. All 3 answers share one ripeness score and differ only by a threshold, so they can never contradict each other (CORAL).

score s = w · features   →   P(grade > k) = σ(s + bk)   →   loss = Σk BCE
